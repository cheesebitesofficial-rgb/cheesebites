# Cheese Bites Pizza 🍕

A modern, high-performance web application and digital ordering platform for Cheese Bites Pizza. Built with React, TypeScript, Vite, dynamic 3D visuals, and Supabase integration.

## ✨ Features
- **Interactive 3D Pizza Experience**: 3D hero canvas & interactive ingredient assembly showcase.
- **Menu & Deals Explorer**: Dynamic product filtering, crust & size customization, real-time pricing.
- **Cart & Seamless Checkout**: Intuitive cart workflow with instant WhatsApp and backend order dispatch.
- **Real-Time Order Tracking**: Multi-step visual timeline tracking from kitchen preparation to delivery.
- **Bilingual Support**: Instant toggle between English and Urdu.
- **Admin & POS Dashboard**: Order management, live status updates, and product catalog control.
- **Fully Responsive**: Optimized for ultra-fast mobile and desktop experiences.

## 🛠️ Tech Stack
- **Framework**: React 19, TypeScript, Vite
- **3D Graphics**: Three.js / Canvas
- **Icons & Animation**: Lucide React, CSS Transitions & Keyframes
- **Backend / Database**: Supabase Client & PostgreSQL Schema
- **Deployment**: Vercel ready (`vercel.json`)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/cheesebitesofficial-rgb/cheesebites.git
cd cheesebites
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables
Copy `.env.example` to `.env` and provide your Supabase credentials (optional for static browsing):
```bash
cp .env.example .env
```

### 4. Run development server
```bash
npm run dev
```

### 5. Build for production
```bash
npm run build
```
